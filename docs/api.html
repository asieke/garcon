HTTP API

The endpoints the dashboard uses, and the fields of a recorded row. Every endpoint answers only requests addressed to this machine (a Host of 127.0.0.1, localhost or [::1]; 403 otherwise), and the read-only ones answer GET only.

GET /api/usage
Every locally recorded row as a JSON array.
GET /api/usage/recent
Returns requests (the latest 30 local arrivals during this server run, oldest arrival first) and total_requests (all locally recorded rows, including history). Each arrival carries sequence. Loaded history is excluded from arrivals; the widget uses its first response as a baseline. Reading this endpoint does not contact model providers.
GET /api/config
How the instance is wired: listen, data, local rows, log bytes, started (Unix milliseconds), version, providers and their upstreams, and implicit harnesses. Setup and doctor use this endpoint to identify Garcon and compare installed and running versions.
GET /api/prices
Model list prices for the cost estimates, USD per million tokens keyed by OpenRouter id: source, fetched_at, models (input, cache_read, cache_write, output), and error/error_at after a failed refresh. The proxy fetches OpenRouter's public model list (no key, nothing about your usage sent) the first time this is asked for and again when the copy is a day old; the last good copy is cached in prices.json next to the usage log.
POST /api/prices
Refresh the catalogue now and return it. Requires a loopback Host.
GET /api/limits
Cached local Codex and Claude subscription snapshots, independent of completion history. Returns accounts, refreshing, updated_at, and an optional error. Each account includes identity, provider, email, workspace, plan, status, last successful fetched_at, and limit windows. Windows contain a label, nullable used_percent, window_seconds, reset timestamp resets_at (Unix milliseconds), and expired. Missing usage is never zero. No credentials are returned.
POST /api/limits/refresh
Request a background collection and return HTTP 202 with the current snapshot. Concurrent refreshes coalesce, with a 30-second minimum interval and provider rate-limit backoff. Requires a loopback Host and rejects a different Origin. Collection also runs at startup and every five minutes without dashboard traffic.

Run garcon doctor for local installation diagnostics.

Row fields

time (unix ms), harness, account, provider, model, status, ms, input, cache_read, cache_write, output, plus optional connection timings the proxy measures for itself: queue_us, reused, connect_ms, dns_ms, tcp_ms, tls_ms, first_byte_ms. Absent means not measured, never zero.
