Dashboard

Find an account, follow a task, inspect a request.

Open localhost:4141. The app refreshes as requests arrive.

Providers
Connected accounts, browser sign-in, and tool configuration. The Codex card shows quota, reset times, health, scores, and pool membership. Connecting an account doesn't automatically enroll it.
Sessions
Codex task names, projects, assigned accounts, and request activity. Search by title, project, account, model, or ID. Click a title for its request history or copy the full session ID. Unavailable titles fall back to IDs.
Analytics
Usage, Cost, and Models tabs with time filters. Cost is an API-equivalent estimate, not a ChatGPT subscription charge. Missing prices are disclosed.
Logs
Searchable request history, including routing errors and interrupted streams. Open a request for its task, account, model, timing, tokens, and errors. Service diagnostics have a separate System tab.

What “active” means

In-flight sessions appear first, with elapsed time. Labels distinguish model responses from background reviews. No model request doesn't mean a task is finished; it may be running tools or waiting for input.

Task names come from Codex's local index. Garcon reads them without changing that index or copying titles into its own database. Existing account assignments survive restarts.

Keep an eye on usage

The bottom ticker shows recent routes and opens the request inspector. Pause it to read an item. The separate usage widget shows subscription allowances, reset countdowns, and Codex reset credits. Press R to refresh.

Provider limits include work outside Garcon. Missing or stale data is labeled rather than treated as zero. About subscription limits.
