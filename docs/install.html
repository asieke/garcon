Install

Build, install and run Garcon as a background service on macOS or Linux.

Needs Go 1.27+ and Node 22+ (mise install in the repository provides both). Works on macOS and Linux.

shell
git clone https://github.com/asieke/garcon && cd garcon
./install.sh            # build dashboard + binary, install ~/.local/bin/garcon
./install.sh --service  # also run it now and at every login
./install.sh --update   # later: pull the latest main, rebuild, restart

--service creates a systemd user unit garcon on Linux (systemctl --user status garcon, journalctl --user -u garcon) or a LaunchAgent dev.garcon on macOS (log in ~/Library/Logs/garcon.log). ./install.sh --update fast-forwards main, rebuilds and restarts a running service (it refuses to run over uncommitted changes). ./install.sh --uninstall removes the service, the binary and the settings file but keeps the usage log.

By hand: garcon [-listen 127.0.0.1:4141] [-data ~/.local/share/garcon/usage.jsonl] [-config ~/.config/garcon/config.json].
