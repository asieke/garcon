Garcon

A local pass-through proxy for coding agents that records usage per account. Two Go files with no dependencies, a dashboard embedded in the binary, and optional sync across your machines through a Supabase project you own.

Each agent is pointed at http://127.0.0.1:4141/<harness>/<account>/<provider>/, where harness names the tool, account is the login it uses (an email), and provider is the upstream. The proxy forwards every request unchanged and streams the reply back. Completion calls are appended to a local log with the model and the token counts the provider reported: uncached input, cache read, cache write and output. No limits, no retries, nothing rewritten, no credentials stored.
