---
name: garcon-add-openrouter
description: Add an OpenRouter API account to Garcon.
---
On the Garcon host (SSH if remote), help me supply my API key privately via stdin to `garcon accounts key openrouter --key-stdin`; never put it in chat, command arguments, logs, or shell history. Use the server's `--data` path if non-default. Check `garcon accounts list` for OpenRouter configuration; this confirms storage, not key validity. Preserve existing settings. OpenRouter is for compatible clients such as Pi, never the Codex pool. Never enable browser writes.
